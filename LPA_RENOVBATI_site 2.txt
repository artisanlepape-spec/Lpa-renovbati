LPA RENOVBATI — site vitrine de départ

Pour ouvrir le site :
1. Décompressez le fichier ZIP.
2. Ouvrez le dossier lpa_renovbati_site.
3. Ouvrez index.html dans un navigateur.

À compléter avant publication :
- confirmer la ville et le code postal de l'adresse ;
- ajouter le téléphone et l'adresse e-mail ;
- remplacer les cadres de galerie par vos photos réelles ;
- vérifier les mentions légales et les informations de l'entreprise.

Cette version est un fichier local : elle n'est pas encore publiée sur Internet.
